# SimpleQRStudio Website

Static website for GitHub Pages.

## Files

- `index.html`: main landing page
- `privacy.html`: privacy policy for App Store Connect
- `support.html`: support page
- `style.css`: shared styling
- `CNAME`: custom domain for GitHub Pages
- `images/`: app icon and screenshots

## Setup

1. Create a GitHub repository.
2. Upload these files to the root of the repository.
3. Go to Settings, Pages.
4. Publish from the main branch and root folder.
5. Set the custom domain to `simpleqrstudio.com`.
6. Enable HTTPS after DNS is configured.

## Replace placeholders

Replace files in the `images` folder with real app assets:

- `app-icon.png`
- `screenshot1.png`
- `screenshot2.png`
- `screenshot3.png`
